# GPDF - Grant's PDF Reader

GPDF is a minimalist, lightweight and efficient PDF reader and annotation editor for Windows x64, built with C++, Qt Widgets and PDFium.

## Why GPDF?

Reading and editing a PDF should be simple yet many PDF applications will clog their interfaces with irrelevant tools, subscription prompts and AI suggestions that get in the way of meaningful work.

GPDF keeps the focus on the document and the user. It provides the essentials for reading, taking notes and organizing your work through a clean interface, with speed and practicality guiding its design.

The complete application was conceived to be lightweight and blazingly fast, taking up about 50 MB in total and 4x less RAM consumption than mainstream PDF Readers in most scenarios.

Originally designed for students and academics, GPDF has proven useful for anyone who wants a straightforward tool for working with PDFs. It is completely free to use and currently in beta.

## Install and run

Simply download and run the installer on Windows x64 and enjoy it.

Link of releases: https://github.com/LautaroGrant/gpdf/releases

## Features

- Open and manage multiple pdfs in a single instance. Continuous, single-page and two-page views, zoom, rotation and full screen.
- Add comments, text boxes, highlights, underlines and pen strokes.
- Day/Night Mode UI settings.
- Tabs, thumbnails, PDF outlines, personal bookmarks and reading progress. 
- Recovery copies and session restoration.
- Annotation export to Markdown, text or HTML.
- Supports printing and print preview.
- Automatic OCR for undigitalized documents.
- Workbench: merge, split, remove, extract and organize pages, and apply OCR to pdf batches.
- Spanish and English language supported.
