# Traducción española de Qt

`qtbase_es.qm` procede del paquete oficial qttranslations de Qt 6.8.3, descargado desde el repositorio Qt mediante aqtinstall. Se incorpora al ejecutable con el sistema de recursos de Qt para traducir botones, cuadros de diálogo, menús contextuales y vista previa. Las licencias de Qt se distribuyen en `third_party/licenses/Qt` y en `licenses/Qt` del paquete final. El campo de atajos tiene una traducción complementaria para versiones que no traducen ese texto.

Los cuadros nativos de Abrir e Imprimir utilizan los textos y el idioma de Windows.
